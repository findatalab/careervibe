# CareerVibe — Карьерный нетворкинг

[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)
[![Python](https://img.shields.io/badge/python-3.10%2B-blue)](https://www.python.org/)
[![Flask](https://img.shields.io/badge/flask-2.3.3-green)](https://flask.palletsprojects.com/)
[![SQLite](https://img.shields.io/badge/sqlite-3-blue)](https://www.sqlite.org/)

**CareerVibe** — это платформа для карьерного нетворкинга, где студенты и молодые специалисты могут задать вопрос профессионалам из ведущих компаний и получить качественный ответ. Проект разработан в рамках лаборатории искусственного интеллекта [Финансового университета при Правительстве РФ](https://en.fa.ru/).

🌐 **Демо:** *скоро*

## 🚀 Возможности

### Пользователи
- ✅ Регистрация и авторизация (по email или никнейму)
- ✅ Хеширование паролей (Werkzeug)
- ✅ Сессии с проверкой валидности
- ✅ Профиль пользователя (аватарка, никнейм, информация о себе, дата регистрации)
- ✅ Редактирование профиля (никнейм, аватарка, bio)

### Вопросы и ответы
- ✅ Создание, просмотр, редактирование, удаление вопросов
- ✅ Добавление, редактирование, удаление ответов
- ✅ Поддержка **Markdown и LaTeX** в вопросах и ответах (редактор EasyMDE с предпросмотром)
- ✅ Голосование за вопросы и ответы (AJAX, подсветка активного голоса)
- ✅ Отметка «Лучший ответ» (только для автора вопроса)
- ✅ Счётчик просмотров вопросов
- ✅ **Вложенные ответы** — возможность отвечать на существующие ответы (1 уровень вложенности)

### Теги
- ✅ Добавление тегов при создании вопроса (через запятую или Enter)
- ✅ Ограничение: максимум 7 тегов, каждый до 20 символов
- ✅ Динамическое добавление/удаление тегов в форме с визуальной обратной связью
- ✅ Цветовая индикация популярности тегов
- ✅ Отдельные страницы для каждого тега
- ✅ **Интерактивная карта всех тегов** — визуализация в виде «пузырьков» с физикой (перетаскивание, настройка отталкивания, центробежной силы и скорости, поиск по тегам, сброс позиций)

### Поиск и фильтрация
- ✅ Поиск по заголовкам и тексту вопросов
- ✅ Поиск по тегам — введите `#тег` в строку поиска
- ✅ Сортировка ленты: новые / популярные

### Файлы и вложения
- ✅ Загрузка файлов к вопросам и ответам
- ✅ Поддерживаемые форматы: изображения (png, jpg, jpeg, gif, webp), видео (mp4, webm, mov, avi), аудио (mp3, wav, ogg), документы и архивы (pdf, txt, zip, rar, doc, docx, xls, xlsx)
- ✅ Максимум 5 файлов на один вопрос/ответ
- ✅ Drag-and-drop загрузка, предпросмотр изображений, встроенные плееры для видео и аудио
- ✅ Удаление вложений (в том числе существующих при редактировании)
- ✅ Модальное окно для увеличения изображений

### Интерфейс
- ✅ Адаптивная вёрстка (мобильные устройства)
- ✅ Бургер-меню на мобильных с выпадающим списком навигации
- ✅ Сайдбар с активными пользователями и популярными тегами
- ✅ Выезжающие уведомления (тосты) с автоматическим исчезновением
- ✅ Анимации карточек, кнопок, аватарок, тегов
- ✅ Sticky-шапка
- ✅ Полноэкранный режим редактора (хэдер скрывается)

### Дополнительные страницы
- ✅ «О проекте» (миссия)
- ✅ «Помощь» — подробное руководство по использованию платформы, Markdown и LaTeX
- ✅ «Правила сообщества» — детальные правила поведения, ограничения и санкции
- ✅ «Контакты» — информация о разработчике, лаборатории и способах связи

## 🛠 Технологии

| Компонент | Технология |
|-----------|------------|
| **Backend** | Python 3.10+, Flask 2.3.3 |
| **Database** | SQLite3 |
| **Frontend** | HTML5, CSS3 (чистый, без фреймворков) |
| **Markdown + LaTeX** | EasyMDE, KaTeX, marked.js |
| **Auth** | Werkzeug (хеширование паролей) |
| **Файлы** | werkzeug.utils.secure_filename |
| **Визуализация тегов** | Интерактивная физика пузырьков (JavaScript Canvas) |

## 📦 Установка и запуск

### Требования
- Python 3.10 или выше
- pip

### Шаги

1. **Клонировать репозиторий**
```bash
git clone https://github.com/Y-deva/careervibe.git
cd careervibe
```

2. **Создать и активировать виртуальное окружение**
```bash
python -m venv venv
# Windows:
venv\Scripts\activate
# Linux / macOS:
source venv/bin/activate
```

3. **Установить зависимости**
```bash
pip install -r requirements.txt
```

4. **Инициализировать базу данных**
```bash
python init_db.py
```

5. **Запустить приложение**
```bash
python app.py
```

6. **Открыть в браузере**
```
http://127.0.0.1:5000
```

## 📁 Структура проекта

```
careervibe/
├── app.py                   # Основное приложение Flask (маршруты, логика)
├── init_db.py               # Скрипт создания базы данных
├── requirements.txt         # Зависимости проекта
├── instance/
│   └── careervibe.db        # База данных SQLite (создаётся после запуска init_db.py)
├── static/
│   ├── style.css            # Все стили проекта
│   ├── avatars/             # Загруженные аватарки пользователей
│   └── uploads/             # Загруженные файлы (вложения к вопросам и ответам)
└── templates/
    ├── base.html            # Базовый шаблон (шапка, футер, тосты)
    ├── index.html           # Главная страница (лента вопросов + сайдбар)
    ├── login.html           # Страница входа и регистрации
    ├── mission.html         # Страница «Миссия»
    ├── help.html            # Страница помощи (руководство по Markdown/LaTeX)
    ├── rules.html           # Правила сообщества
    ├── contacts.html        # Контакты
    ├── all_tags.html        # Интерактивная карта всех тегов (пузырьки)
    ├── ask_question.html    # Создание нового вопроса
    ├── question_detail.html # Детальная страница вопроса
    ├── edit_question.html   # Редактирование вопроса
    ├── edit_answer.html     # Редактирование ответа
    ├── profile.html         # Профиль пользователя
    ├── edit_profile.html    # Редактирование профиля
    ├── search.html          # Результаты поиска
    └── tag_questions.html   # Вопросы по тегу
```

## 🔗 API Endpoints

| Маршрут | Метод | Описание |
|---------|-------|----------|
| `/` | GET | Главная страница (лента вопросов) |
| `/login` | GET, POST | Вход и регистрация (поддержка email/никнейма) |
| `/logout` | GET | Выход из аккаунта |
| `/ask` | GET, POST | Создание вопроса (с тегами и файлами) |
| `/question/<id>` | GET | Детальная страница вопроса |
| `/question/<id>/edit` | GET, POST | Редактирование вопроса |
| `/question/<id>/delete` | POST | Удаление вопроса |
| `/question/<id>/vote` | POST | Голосование за вопрос (AJAX) |
| `/answer/<id>/add` | POST | Добавление ответа (с поддержкой parent_id для вложенности) |
| `/answer/<id>/edit` | GET, POST | Редактирование ответа |
| `/answer/<id>/delete` | POST | Удаление ответа |
| `/answer/<id>/vote` | POST | Голосование за ответ (AJAX) |
| `/answer/<id>/best` | POST | Отметка лучшего ответа |
| `/tag/<name>` | GET | Вопросы по тегу |
| `/tags` | GET | Интерактивная карта всех тегов |
| `/profile/<id>` | GET | Профиль пользователя |
| `/profile/edit` | GET, POST | Редактирование профиля (аватарка, никнейм, bio) |
| `/search` | GET | Поиск вопросов (поддерживается `#тег`) |
| `/mission` | GET | Страница «Миссия» |
| `/help` | GET | Страница помощи |
| `/rules` | GET | Правила сообщества |
| `/contacts` | GET | Контакты |
| `/uploads/<filename>` | GET | Доступ к загруженным файлам |
